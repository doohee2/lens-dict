우리는 스마트폰 카메라로 텍스트를 비추면 Tesseract.js(OCR)를 통해 단어를 인식하고, 브라우저 로컬(IndexedDB/Dexie.js)에 저장된 오프라인 StarDict 사전 데이터를 즉시 검색해 뜻을 알려주는 PWA 기반 스마트 돋보기 앱 'Lens Dictionary'를 만들 거야. 한글 제목은 "단서 찾기 돋보기"
React, Tailwind CSS, 그리고 Lucide 아이콘을 기반으로, 모바일 환경에서 야외나 이동 중에도 한 손으로 쉽게 조작할 수 있는 직관적이고 반응형에 최적화된 UI 컴포넌트를 디자인해 줘.

[1. 전역 레이아웃 및 상단 바 (App Header)]


상단 바는 좌측에 앱 로고('Lens Dictionary')와 사용법을 안내하는 'i' (정보) 아이콘을 배치해.

상단 바 우측에는 다크모드/라이트모드 전환 아이콘과, 사전 데이터를 관리할 수 있는 [⚙️ 사전 데이터 관리] 버튼을 배치해 줘.

단, 100MB 크기의 오프라인 사전(StarDict) 파싱이 완료되어 로컬 DB(Dexie.js)에 적재된 상태라면, 우측 상단이나 하단에 [🟢 오프라인 검색 준비됨] 상태 배지를 띄워 줘. 데이터가 없다면 [⚠️ 사전 데이터 없음 - 탭하여 추가] 배지로 변경해 줘.
[2. 핵심 워크스페이스: 모바일 뷰파인더 및 하단 바텀 시트 (Camera & Bottom Sheet)]
이 앱은 모바일 카메라 활용이 주 목적이므로, 화면 전체를 수직 분할(위: 카메라, 아래: 사전 결과) 형태로 구성해 줘.


[상단 패널: 카메라 뷰어 영역 (View Finder)]


메인 뷰어: <video playsinline> 태그를 활용해 모바일 사파리/크롬에서 전체화면으로 튀어나가지 않는 카메라 스트리밍 화면을 구성해 줘.

오버레이 UI: 카메라 화면 정중앙에 텍스트를 맞출 수 있는 둥근 모서리의 '스캔 가이드라인(조준선)' 사각형을 반투명하게 그려 줘.

하단 컨트롤 바: 스캔 가이드라인 바로 아래에 직관적이고 큼직한 [📷 단어 스캔] 셔터 버튼을 중앙에 배치하고, 그 옆에 [🔦 플래시 켜기/끄기] 아이콘(지원 기기용)을 둬.

피드백 UI: 셔터를 누르면 화면이 잠시 멈추고(Freeze), OCR이 인식한 텍스트 영역 위에 하이라이트 박스가 표시되도록 디자인해 줘.

[하단 패널: 검색 및 사전 결과 창 (Dictionary Results)]


모바일 화면 하단에 고정된 시트(Bottom Sheet) 형태로 디자인하고, 위아래로 스와이프하여 높이를 조절할 수 있는 핸들러(Puller)를 상단에 달아 줘.

상단 검색바: OCR로 인식된 텍스트가 자동으로 입력되는 <input> 필드를 배치해. 인식 오류를 대비해 사용자가 직접 텍스트를 수정할 수 있어야 하고, 우측에 입력 내용을 지우는 [X] 버튼을 둬.

결과 출력부: 로컬 DB에서 검색된 단어의 뜻, 발음 기호, 예문이 깔끔한 타이포그래피로 렌더링되게 해 줘. 시력이 좋지 않은 사용자를 위해 폰트 크기는 기본적으로 큼직하게 설정해.

액션 버튼: 결과 하단에 [🔖 내 단어장에 추가] 버튼을 두어 1번 프로젝트인 'Word Smart'와 연동할 수 있는 여지를 남기고, 로컬 사전에서 뜻을 찾지 못했을 때를 대비한 [🌐 네이버 사전에서 검색] 외부 링크 버튼을 배치해 줘.
[3. 태블릿/PC 반응형 대응 (Desktop Fallback)]


태블릿이나 PC 등 화면 너비가 넓어질 때는 수직 분할(상하)을 해제하고, 화면을 좌우 분할(비율 5:5)하는 단일 행(Single Row) 레이아웃으로 자동 전환해 줘.

좌측은 웹캠 스트리밍 또는 [📂 이미지 파일 업로드] 영역으로 전환하고, 우측 패널은 카메라를 가리지 않는 넓은 사전 검색 결과 창 및 단어장 히스토리 리스트로 활용하도록 구성해 줘.
[4. 스타일 가이드 (Tone & Manner)]


돋보기(확대경)라는 컨셉에 맞게 UI 요소는 큼직하고 시인성이 높아야 해.

카메라 화면 주변은 집중도를 높이기 위해 차분한 검은색(또는 어두운 반투명 오버레이)을 베이스로 사용하고, 포인트 컬러로는 스캐너 느낌을 주는 네온 그린(Neon Green)이나 앰버(Amber) 컬러를 사용해 줘.

다크모드 완벽 지원(dark: 클래스 철저 적용) 및 모바일 터치 최적화(셔터 버튼과 탭 버튼 클릭 영역을 48px 이상으로 여유 있게 확보)를 준수해 줘.

스마트폰 바탕화면에 추가했을 때 돋보기 안에서 텍스트가 빛나는 듯한 형상의 PWA 용 앱 아이콘 컴포넌트(SVG)도 함께 만들어서 제공해 줘.
